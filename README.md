# Runner

Red social para runners y caminantes: recorridos GPS con mapa, fotos y videos del momento, comunidad por ciudad y exploración compartida.

La documentación del proyecto vive en `docs/`:

- `docs/planificacion.md` — qué se construye (historias, RF, RNF, reglas R-xx, decisiones D-xx).
- `CONSTITUCION.md` — stack exacto, reglas duras, comandos, definición de terminado.
- `docs/specs/` — una carpeta `NNN-nombre/` por funcionalidad (`spec.md` + `tasks.md`).
- `docs/agents/` — roles de los subagentes del ciclo SDD + TDD + adversarial.
- `docs/PROGRESS.md` / `docs/CONTINUAR.md` — estado actual y contexto para retomar.

Metodología: cada funcionalidad se especifica, se aprueba, se prueba en rojo, se implementa, se ataca de forma adversarial y se revisa antes de integrarse.
